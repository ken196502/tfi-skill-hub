# TFI Skill Hub 产品功能说明（测试人员版）

> 本文档只讲「产品能做什么、用户怎么操作」，不涉及任何技术实现、接口或部署细节。
> 测试人员可据此核对界面与交互是否符合预期。

---

## 1. 产品简介

TFI Skill Hub 是一个**技能库（Skill Hub）**。注册用户可以在这里**浏览技能、收藏感兴趣的技能，并下载技能文件**。

- **技能（Skill）**：一段可被 AI 智能体调用的能力说明，由 `SKILL.md` 等文件组成。

> 普通用户没有发布、管理、审核等管理员功能，只能进行下方列出的三类操作。

---

## 2. 用户能做什么

普通注册用户只能进行以下三类操作：

1. **注册账号**
2. **收藏 / 取消收藏**技能
3. **下载技能**

---

## 3. 注册账号（`/register`）

- 字段：用户名、密码（≥ 8 位）、显示名称（可选）、邮箱（可选）。
- 用户名规则：2–32 位，可用字母、数字、点、短横线、下划线，且以字母或数字开头。
- 提交注册后账号状态为**待审核**，**需管理员审核通过后才能登录**；登录时若提示「账号待审核」即表示尚未通过。

---

## 4. 收藏 / 取消收藏

- 在技能详情页（或技能卡片）点击**收藏**按钮即可收藏该技能；收藏后按钮显示**已收藏**，再次点击即**取消收藏**。
- 收藏状态仅对当前登录账号生效，可在顶部「收藏」页（`/favorites`）查看已收藏的技能列表。

---

## 5. 下载技能

- 打开任意技能详情页，点击**「下载 ZIP」**按钮，即可把该技能的文件打包下载到本地。
- 下载需要登录账号；未登录时按钮会提示「登录后下载」。

---

## 6. 管理员功能（仅 admin 账号）

> 以下模块只有角色为 `admin` 的账号才能进入（地址以 `/admin` 开头）。普通注册用户看不到，也不需要使用——它们不属于测试人员的日常操作范围。

| 模块 | 功能 |
|---|---|
| **总览** | 展示用户 / 技能 / 插件 / 首页精选的数量统计 |
| **用户管理** | 创建用户、调整角色（普通用户 / 管理员）、封禁账号、为账号签发 Token；按状态（待审核 / 已通过 / 已驳回）筛选，逐条**通过或驳回**注册申请（驳回可填理由） |
| **内容审核** | 审核技能与插件（通过 / 拒绝）；设置**公开或私有**可见性；按 待审核 / 全部 / 公开 / 私有 筛选 |
| **首页精选** | 选择首页展示的精选技能，最多 12 个，顺序按勾选保存 |
| **API Keys** | 签发管理端专用密钥，按用途授权（读取 / 发布 / 删除 / 审核 / 用户审核）；可绑定命名空间、设有效期（长期 / 30 / 90 / 365 天）、撤销；完整密钥仅显示一次 |
| **审计日志** | 查看管理员在用户、内容、首页配置上的操作记录，可按操作 / 资源筛选，含时间、操作、资源、详情、来源 IP |

---

## 7. 给测试人员的注意点

- **收藏不影响下载**：收藏只是把技能加入你的收藏列表，不改变技能本身，也不影响下载。
- **下载得到压缩包**：下载会把该技能当前文件打包成一个 ZIP 压缩文件保存到本地。
- **管理员功能与上述无关**：第 6 节的管理后台仅 `admin` 账号可用，普通测试账号无需使用；如果误以普通账号访问 `/admin` 会被跳转到登录页。
- 如界面行为与本说明不一致，以实际产品为准，并请反馈给开发同学。
