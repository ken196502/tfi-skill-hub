# TFI Skill Hub 产品功能说明（测试人员版）

> 本文档只讲「产品能做什么、用户怎么操作」，不涉及任何技术实现、接口或部署细节。
> 测试人员可据此核对界面与交互是否符合预期。

---

## 1. 产品简介

TFI Skill Hub 是一个**自托管的 AI 智能体技能与插件注册中心**。

- **技能（Skill）**：一段可被 AI 智能体调用的能力说明，以 `SKILL.md` 等文件组成。
- **插件（Plugin）**：把多个技能与 MCP 服务打包在一起的更大的能力包。

团队在这里集中**发布、查找、安装、管理**这些能力。任何人都能浏览公开内容；登录后可以发布自己的技能、组建团队空间并协作。

---

## 2. 角色与权限

| 角色 | 能做什么 |
|---|---|
| **游客（未登录）** | 浏览首页、技能/插件列表与详情、搜索、查看公开内容。**不能**下载、发布、评论。 |
| **注册用户（已审核通过）** | 在游客基础上，可发布技能、创建/加入命名空间、收藏/评分/评论、管理个人 Token。 |
| **命名空间成员** | 按所在空间的角色区分：`owner` / `admin` / `member` 可发布；`reader` 只能看、不能发布。 |
| **管理员（admin）** | 额外可使用「管理后台」：用户审核、内容审核、首页精选、审计日志、API Key 签发。 |

> 账号只有两种角色：`user` 与 `admin`。命名空间内部另有 `owner / admin / member / reader` 四级。

---

## 3. 公开浏览

### 3.1 首页（`/`）
- **精选技能**：由管理员配置、横向展示的一组推荐技能。
- **热门技能**：按下载量排序的技能。
- 顶部**搜索框**：输入后回车进入搜索结果页。

### 3.2 技能列表（`/skills`）
- 左侧**分类筛选**：金融 / 个人 / 工作区 / 通用。
- **排序方式**：最新 / 最近更新 / 下载量 / 收藏数 / 名称。
- 搜索框 + 「加载更多」分页。

### 3.3 技能详情（`/skills/@命名空间/标识名`）
- **说明正文**：优先展示发布者/管理员设置的富文本；没有则展示 `SKILL.md`。
- **下载 ZIP**（需登录）。
- 侧栏信息：最新版本、发布者、创建/更新时间、标签、**版本历史**（被撤回的版本会标记「已撤回」）。

### 3.4 插件列表与详情（`/plugins`）
- 浏览插件包（内含技能与 MCP 服务）。
- 排序同技能列表；详情页展示简介与下载入口。

### 3.5 搜索（`/search`）
- 按**名称、摘要、标签、SKILL.md 正文**检索。
- **中文关键词至少 3 个字**才会触发全文检索；2 字以内会退化为模糊匹配，结果可能不全。
- 结果同时包含技能与插件，混排展示。

## 4. 账号体系

### 4.1 注册（`/register`）
- 字段：用户名、密码（≥ 8 位）、显示名称（可选）、邮箱（可选）。
- 用户名规则：2–32 位，可用字母、数字、点、短横线、下划线，且**以字母或数字开头**。
- 提交后账号状态为**待审核**，**不能立即登录**。
- 若管理员关闭了公开注册，注册入口会隐藏、提交也会被拒绝。

### 4.2 登录 / 登出
- 用「用户名 + 密码」登录。
- **待审核**账号登录会提示「账号待审核」；**被驳回**账号登录会提示「账号已驳回」。

### 4.3 账号审核（管理员）
- 在「用户管理」按状态筛选：待审核 / 已通过 / 已驳回。
- 逐行「通过 / 驳回」；驳回可填写理由。
- 审核**通过后**该账号才能登录；被驳回仍不能登录，但记录会保留（不会删除账号，用户名也不会被他人重复注册）。

## 5. 发布技能（`/publish`）

需登录。表单字段：

| 字段 | 说明 |
|---|---|
| 标识名（slug） | 仅限小写字母、数字、连字符，如 `code-review` |
| 版本号 | 语义化版本，如 `1.0.0`；同一 slug 重复版本号会冲突 |
| 显示名称 | 展示用名称 |
| 简介 | 一句话说明 |
| 分类 | 金融 / 个人 / 工作区 / 通用 |
| 可见性 | 私有（默认）/ 公开（公开需管理员审核通过后才对外可见） |
| 归属命名空间 | 留空则发布到个人空间 |
| 标签 | 逗号分隔 |
| 更新日志 | 本版本变更说明 |
| 技能文件 | **必须包含 `SKILL.md`**，支持文件夹与多文件（拖放或选择） |

- 发布成功后可跳转到该技能详情页。
- 被软删除的技能，用相同 slug 重新发布会自动恢复。

---

## 6. 命名空间 / 团队空间（`/namespaces`）

- 登录后可**创建团队命名空间**（标识名 + 显示名称 + 描述）。
- 进入某个命名空间后有三类标签页：
  - **成员**：添加/移除成员，设定角色（`member` / `admin` / `reader`）。
  - **邀请**：按用户名发出邀请并指定角色，记录邀请状态（待接受/已接受等）。
  - **团队 Token**（仅团队空间有）：创建带作用域（`publish` / `read`）和有效期的 Token；**创建后完整 Token 仅显示一次**，可随时吊销。
- 个人空间（`personal`）没有「团队 Token」标签页。

---

## 7. 个人 Token

- 用户在个人设置中可签发**个人 Token**，作用域：`full`（全部）/ `read`（只读）/ `publish`（仅发布）。
- 个人 Token 等同于账号本身，能调用该账号权限范围内的所有操作。

---

## 8. 社交功能

- **收藏（Star）**、**评分（Rating）**、**评论（Comment）**：均需登录。
- **通知（Notifications）**：互动与待办提醒。

---

## 9. 管理后台（`/admin`，仅 admin）

| 模块 | 功能 |
|---|---|
| 概览 | 用户 / 技能 / 插件 / 首页精选的数量统计 |
| 首页精选 | 配置首页精选技能及展示顺序（最多 12 个） |
| 用户管理 | 创建用户、调整角色、封禁账号、签发 Token、审核注册 |
| 内容审核 | 审核技能与插件（通过/驳回）；管理公开 / 私有 / 未公开（unlisted）状态；撤回（yank）/ 弃用（deprecate） |
| 审计日志 | 追踪管理员在用户、审核、首页精选上的操作记录 |
| API Key | 签发「管理端专用 Key」，按用途授权（`skills:read` / `skills:publish` / `skills:delete` / `skills:moderate` / `users:moderate`），可绑定命名空间、设有效期、撤销；**明文仅显示一次** |

> 管理端 API Key 与「个人 Token」是两回事：Key 只拥有被授权的那一项能力，且可绑定命名空间、设有效期、单独撤销。

---

## 10. 下载与安装

- 技能详情页的 **「下载 ZIP」** 按钮（需登录）会把该技能当前所有文件打包下载。
- 单个文件（如 `SKILL.md`）的读取是公开的。
- 打包下载类操作需要登录。

---

## 11. 给测试人员的注意点

- **注册需审核**：新账号提交后默认不能登录，必须管理员通过。
- **公开技能需审核**：选「公开」发布的技能，要等管理员审核通过才在公开列表与搜索中可见；选「私有」仅自己/所在命名空间可见。
- **限流**：连续大量请求（尤其下载、发布）会触发限流（返回 429 并带 `Retry-After`）；正常手动操作不会遇到。
- **文件大小**：单个文件 ≤ 5 MB，单次上传文件数 ≤ 500。
- **中文搜索**：关键词至少 3 个字才有全文检索效果。
- **一次性密钥**：团队 Token 与管理端 API Key 创建后明文只显示一次，务必立即复制保存。
- **命名空间角色**：`reader` 只能查看，不能发布。
