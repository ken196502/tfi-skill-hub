# TFI Skill Hub 产品功能说明（测试人员版）

> 本文档只讲「产品能做什么、用户怎么操作」，不涉及任何技术实现、接口或部署细节。
> 测试人员可据此核对界面与交互是否符合预期。

---

## 1. 产品简介

TFI Skill Hub 是一个**技能库（Skill Hub）**。注册用户可以在这里**浏览技能、收藏感兴趣的技能，并下载技能文件**。

- **技能（Skill）**：一段可被 AI 智能体调用的能力说明，由 `SKILL.md` 等文件组成。

> 普通用户没有发布、管理、审核等管理员功能，只能进行下方列出的三类操作。

---

## 2. 用户能做什么

普通注册用户只能进行以下三类操作：

1. **注册账号**
2. **收藏 / 取消收藏**技能
3. **下载技能**

---

## 3. 注册账号（`/register`）

**需要填写的字段**

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 用户名 | 必填 | 2–32 位，可用字母、数字、点、短横线、下划线，且以字母或数字开头。登录时使用 |
| 姓名 | 必填 | 你的真实姓名 |
| 邮箱 | 必填 | 常用邮箱地址，用于接收后续通知 |
| 邮箱验证码 | 必填 | 点「发送验证码」后**统一填 `123456`**（见下方说明） |
| 所在国家或地区 | 必填 | 输入关键字搜索，或展开下拉选择 |
| 机构名称 | 必填 | 你所在的公司 / 机构 |
| 岗位 | 必填 | 你的职位 |
| 办公地区 | 选填 | 例如「上海」；可留空 |
| 希望获得的研究支持 | 必填 | 简述你的研究需求 |
| 关注市场 | 必填 | **可多选**，至少选一项（A股 / 港股 / 美股 / 海外市场 / 固定收益 / 大宗商品 / 外汇 / 基金与 ETF / 私募与另类投资） |
| 密码 | 必填 | 至少 8 位，需与「确认密码」一致 |

> **关于邮箱验证码**：系统尚未接入邮件服务，验证码是固定值 **`123456`**，不区分邮箱地址。

**获取验证码的步骤**

1. 先填写**邮箱**（未填写时点发送不会有反应）。
2. 点验证码框右侧的**「发送验证码」**按钮。
3. 按钮变为**「N 秒后重发」**并置灰 **60 秒**，期间不可再次点击。
4. 在验证码框填入 `123456`，继续填写其余字段并提交。

**关于倒计时**

- 倒计时**按邮箱计算**：换一个邮箱地址，按钮会立即恢复可用（每个地址各有 60 秒）。
- 倒计时**刷新页面不会重置**：等待由服务端记录，刷新后仍显示剩余秒数。
- 60 秒结束后按钮变回**「重新发送」**，可再次发送。
- 修改邮箱地址后，之前填写的验证码会被清空，需要对新地址重新获取。

**其他规则**

- 提交注册后账号状态为**待审核**，**需管理员审核通过后才能登录**；登录时若提示「账号待审核」即表示尚未通过。
- 提交成功后不会立即登录，需回到登录页用刚注册的账号登录。
- 验证码或任一必填项未填 / 填错时，页面会在对应字段下方给出红色提示，且**不会提交**。
- 换一个国家或地区可以直接重新输入关键字筛选，下拉列表会实时过滤。

---

## 4. 收藏 / 取消收藏

- 在技能详情页（或技能卡片）点击**收藏**按钮即可收藏该技能；收藏后按钮显示**已收藏**，再次点击即**取消收藏**。
- 收藏状态仅对当前登录账号生效，可在顶部「收藏」页（`/favorites`）查看已收藏的技能列表。

---

## 5. 下载技能

- 打开任意技能详情页，点击**「下载 ZIP」**按钮，即可把该技能的文件打包下载到本地。
- 下载需要登录账号；未登录时按钮会提示「登录后下载」。

---

## 6. 管理员功能（仅 admin 账号）

> 以下模块只有角色为 `admin` 的账号才能进入（地址以 `/admin` 开头）。普通注册用户看不到，也不需要使用——它们不属于测试人员的日常操作范围。

| 模块 | 功能 |
|---|---|
| **总览** | 展示用户 / 技能 / 首页精选的数量统计 |
| **用户管理** | 创建用户、调整角色（普通用户 / 管理员）、封禁账号、按状态（待审核 / 已通过 / 已驳回）筛选，逐条**通过或驳回**注册申请（驳回可填理由）；**待审核**的账号会**自动展开**注册资料（姓名、邮箱、所在国家或地区、机构名称、岗位、办公地区、关注市场、研究需求），其余账号点「查看资料」展开。**已通过的账号不能再驳回**——如需收回其访问权，请使用「封禁」 |
| **内容管理** | 增删技能，维护展示信息（名称 / 简介 / 分类 / 标签）与详情正文（富文本）；名称、简介、正文都分中英文两份，用表单里的**编辑语言**开关切换填写；弹窗内可直接**上传技能文件夹**（新建时必须含 `SKILL.md`；编辑时上传的文件会发布为新版本，不传则文件保持不变）；可随时**上架 / 下架**，或**删除**（删除不可恢复）；列表按 全部 / 已上架 / 已下架 筛选并分页 |
| **首页精选** | 选择首页展示的精选技能，最多 12 个，顺序按勾选保存 |
| **API Keys** | 签发管理端专用密钥，按用途授权（读取 / 发布 / 删除 / 上下架 / 用户审核）；可绑定命名空间、设有效期（长期 / 30 / 90 / 365 天）、撤销；完整密钥仅显示一次 |
| **审计日志** | 查看管理员在用户、内容、首页配置上的操作记录，可按操作 / 资源筛选，含时间、操作、资源、详情、来源 IP |

---

## 7. 给测试人员的注意点

- **收藏不影响下载**：收藏只是把技能加入你的收藏列表，不改变技能本身，也不影响下载。
- **下载得到压缩包**：下载会把该技能当前文件打包成一个 ZIP 压缩文件保存到本地。
- **管理员功能与上述无关**：第 6 节的管理后台仅 `admin` 账号可用，普通测试账号无需使用；如果误以普通账号访问 `/admin` 会被跳转到登录页。
- 如界面行为与本说明不一致，以实际产品为准，并请反馈给开发同学。
