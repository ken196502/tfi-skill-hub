# 周边陆地轮廓

`surrounding-land.js` 只用于探索地图样式二的地理背景，不含国家边界或产业数据，不替代现有中国地图和湖北城市地图。

## 来源和许可

- Natural Earth `ne_50m_land`，固定使用 `natural-earth-vector` 的 `v5.1.2` 版本。
- 原始文件：`https://cdn.jsdelivr.net/gh/nvkelso/natural-earth-vector@v5.1.2/geojson/ne_50m_land.geojson`
- 上游项目：`https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2`
- 数据属于公有领域（public domain）；许可说明：`https://www.naturalearthdata.com/about/terms-of-use/`
- 制作时核对日期：2026-10-24。页面运行时只加载本地文件。

## 预处理

1. 用 Shapely 合并原始陆地多边形及经度向东平移 360° 的副本，消除日期变更线接缝；使用 0.04° 容差进行保拓扑简化。
2. 将填充多边形裁剪到经度 0°–225°、纬度 −90°–90°，覆盖固定镜头可能看到的区域。裁剪边缘位于当前球面映射的背面。
3. 海岸线单独从裁剪前的陆地边界与裁剪框求交得到，不将人工裁剪边界绘制成海岸线。
4. 使用下列映射转换为现有中国 SVG 的坐标，保留两位小数。映射由 GeoJSON.CN 中国行政区划 1.6.3 与现有 34 个省级 SVG 的对应起点拟合，最大样本误差小于 0.007 个 SVG 单位。

```text
x = longitude × 7.517753956451605 − 499.5912819639199
y = latitude × (−8.514362861574817) + 520.0817751711731
```

产物包含 `polygons`（`contour` 和 `holes`）及独立的 `coastlines` 折线，保留跨日期变更线的连续陆地和原始孔洞。渲染时与中国/湖北共用 `onSphere`，这是展示性球面映射，不是测绘投影。

陆地填充半径为 1.00045，海岸线半径为 1.0008，低于中国省份及湖北城市共同使用的 1.001；不加入城市射线拾取列表。

## 湖北边界对齐

`hubei-aligned.js` 是从仓库现有 `china-map-data.js` 和 `hubei-map-data.js` 派生的样式二显示几何，不引入新的行政区划来源，也不修改原始数据、城市 ID、标签或跳转关系。

- 以全国地图中 `420000` 的省界为统一外边界，把市级几何转换到全国地图坐标后裁剪，并消除因不同轮廓精度造成的越界和重叠。
- 细小未覆盖区域归入共享边界最长的相邻市；不相邻的微小孤立区域归入最近的原市域。原市域主体和内部划分保持不变。
- 在百万分之一个 SVG 单位精度下进行几何运算；生成时验证市域覆盖省域、彼此无显著重叠、各市至少保留 98% 原覆盖面积，且序列化后的多边形有效。
- 市内边界由相邻市域的共享边线提取，只绘制一次。省界直接使用全国地图同一条路径，不再按半径额外放大。
- 全国省份和湖北城市使用相同球面半径，不叠加湖北省底面；消除深度差产生的透视错位。

原始地图更新后，使用 Python 3 和 Shapely 2.x 重新生成显示资源，并复核缩放与点击：

```sh
python3 scripts/build-hubei-alignment.py > assets/map/hubei-aligned.js
```

Shapely 只在离线生成时需要，页面运行不增加第三方依赖。
