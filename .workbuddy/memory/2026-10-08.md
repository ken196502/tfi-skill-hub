# 2026-10-08

## 新增：给测试人员的产品功能文档 + 可部署静态页
- 产出 `docs/product-guide.md`（纯功能说明，无技术细节，中文）与 `static/product-guide.html`
  （自包含、中英双语切换、品牌色 #004123、Helvetica、零外链）。
- 改造 `scripts/serve.mjs`：从 `SKILLHUB_STATIC_DIR`（容器默认 `/app/static`）提供 `/docs/*`
  静态文件，`Cache-Control: no-cache`，使文档更新无需重新构建镜像。
- `Dockerfile` 把 `static/` 拷入镜像；`docker-compose.yml` 设 `SKILLHUB_STATIC_DIR=/app/static`
  并 `bind mount ./static:/app/static`。
- 验证：临时库 + 临时端口起 serve.mjs，`curl /docs/product-guide.html` → 200 / no-cache / 29KB /
  含标题；缺失文档 → 404。
- 注意：`api-usage.md` 里仍含一把明文 admin API Key，属历史遗留安全隐患，本次未改。
