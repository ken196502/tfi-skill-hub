## 全站字体切换为 D-DIN
- 需求：用户要求界面字体用 D-DIN。
- 来源确认：用户给的 FontSquirrel 链接即 Datto 开源 D-DIN（DIN 1451，SIL OFL 1.1），
  与从 `amcchord/datto-d-din` 镜像拉取的 woff2 为同一套。
- 下载 `D-DIN.woff2 / D-DIN-Bold.woff2 / D-DIN-Italic.woff2`（各 ~20KB）到 `src/styles/fonts/`，
  并附带 `OFL-1.1.txt`。D-DIN 基础字族无 Bold-Italic，删掉了原 404 的该文件。
- 改动 `src/styles/global.css`：新增 3 段 `@font-face`（本地 url，font-display:swap），
  `--font-heading` / `--font-body` 改为 `"D-DIN"`（保留中文回退），`.logo` 字标也统一成 D-DIN。
- 验证：`npm run build` 通过；3 个 woff2 被打进 `dist/client/assets/*` 且 CSS 引用
  `url(/assets/D-DIN-*.woff2)`。`scripts/serve.mjs` 已含 `font/woff2` MIME，生产可正常返回。
- 备注：纯前端资产改动，未重跑 smoke（无 API/契约变化）。
