1. 产品简介1. Overview

TFI Skill Hub 是一个自托管的 AI 智能体技能与插件注册中心。TFI Skill Hub is a self-hosted registry for AI-agent skills and plugins.

  • 技能（Skill）：一段可被 AI 智能体调用的能力说明，由 SKILL.md 等文件组成。Skill: a capability description an AI agent can call, composed of files such as SKILL.md.
  • 插件（Plugin）：把多个技能与 MCP 服务打包在一起的更大能力包。Plugin: a larger package bundling multiple skills and MCP services.

团队在这里集中发布、查找、安装、管理这些能力。任何人都能浏览公开内容；登录后可以发布自己的技能、组建团队空间并协作。Teams use it to publish, find, install, and manage these capabilities. Anyone can browse public content; after signing in you can publish your own skills and collaborate in team spaces.

3. 公开浏览3. Public browsing

3.1 首页（/）3.1 Home (/)

  • 精选技能：由管理员配置、横向展示的一组推荐技能。Featured skills: a curated row of recommended skills set by an admin.
  • 热门技能：按下载量排序的技能。Popular skills: skills ranked by downloads.
  • 顶部搜索框：输入后回车进入搜索结果页。Top search box: pressing Enter opens the search results page.

3.2 技能列表（/skills）3.2 Skill list (/skills)

  • 左侧分类筛选：金融 / 个人 / 工作区 / 通用。Left category filter: Finance / Personal / Workspace / General.
  • 排序方式：最新 / 最近更新 / 下载量 / 收藏数 / 名称。Sort: Newest / Recently updated / Downloads / Stars / Name.
  • 搜索框 + 「加载更多」分页。Search box + "Load more" pagination.

3.3 技能详情（/skills/@命名空间/标识名）3.3 Skill detail (/skills/@namespace/slug)

  • 说明正文：优先展示发布者/管理员设置的富文本；没有则展示 SKILL.md。Body: shows the rich-text set by the publisher/admin first; otherwise the SKILL.md.
  • 下载 ZIP（需登录）。Download ZIP (requires sign-in).
  • 侧栏信息：最新版本、发布者、创建/更新时间、标签、版本历史（被撤回的版本会标记「已撤回」）。Sidebar: latest version, publisher, created/updated time, tags, version history (yanked versions are marked "yanked").

3.4 插件列表与详情（/plugins）3.4 Plugin list & detail (/plugins)

  • 浏览插件包（内含技能与 MCP 服务）。Browse plugin packages (containing skills and MCP services).
  • 排序同技能列表；详情页展示简介与下载入口。Same sorting as the skill list; the detail page shows the summary and a download link.

3.5 搜索（/search）3.5 Search (/search)

  • 按名称、摘要、标签、SKILL.md 正文检索。Search by name, summary, tags, and SKILL.md content.
  • 中文关键词至少 3 个字才会触发全文检索；2 字以内会退化为模糊匹配，结果可能不全。Chinese keywords need at least 3 characters for full-text search; 1–2 characters fall back to fuzzy matching and may miss results.
  • 结果同时包含技能与插件，混排展示。Results mix skills and plugins in one list.

4. 账号体系4. Accounts

4.1 注册（/register）4.1 Register (/register)

  • 字段：用户名、密码（≥ 8 位）、显示名称（可选）、邮箱（可选）。Fields: username, password (≥ 8 chars), display name (optional), email (optional).
  • 用户名规则：2–32 位，可用字母、数字、点、短横线、下划线，且以字母或数字开头。Username rule: 2–32 chars, letters/digits/dot/dash/underscore, and must start with a letter or digit.
  • 提交后账号状态为待审核，不能立即登录。After submitting, the account is pending review and cannot sign in yet.
  • 若管理员关闭了公开注册，注册入口会隐藏、提交也会被拒绝。If the admin disables open registration, the entry is hidden and submissions are rejected.

4.2 登录 / 登出4.2 Sign in / out

  • 用「用户名 + 密码」登录。Sign in with username + password.
  • 待审核账号登录会提示「账号待审核」；被驳回账号登录会提示「账号已驳回」。A pending account sees "account pending"; a rejected account sees "account rejected".

4.3 账号审核（管理员）4.3 Account review (admin)

  • 在「用户管理」按状态筛选：待审核 / 已通过 / 已驳回。In "User management", filter by status: pending / approved / rejected.
  • 逐行「通过 / 驳回」；驳回可填写理由。Approve or reject row by row; rejection may include a reason.
  • 审核通过后该账号才能登录；被驳回仍不能登录，但记录会保留（不会删除账号，用户名也不会被他人重复注册）。Only after approval can the account sign in. A rejected account still cannot, but the record is kept (the account is not deleted and the username cannot be re-registered).

6. 命名空间 / 团队空间6. Namespaces / teams

  • 登录后可创建团队命名空间（标识名 + 显示名称 + 描述）。After signing in you can create a team namespace (slug + display name + description).
  • 进入某个命名空间后有三类标签页：A namespace has three tabs:
  • 成员：添加/移除成员，设定角色（member / admin / reader）。Members: add/remove members and set their role (member / admin / reader).
  • 邀请：按用户名发出邀请并指定角色，记录邀请状态。Invitations: invite by username with a role; invitation status is tracked.
  • 团队 Token（仅团队空间有）：创建带作用域（publish / read）和有效期的 Token；创建后完整 Token 仅显示一次，可随时吊销。Team tokens (team spaces only): create a token with a scope (publish / read) and expiry; the full token is shown only once and can be revoked anytime.

个人空间（personal）没有「团队 Token」标签页。A personal space (personal) has no "Team tokens" tab.

7. 个人 Token7. Personal tokens

  • 用户在个人设置中可签发个人 Token，作用域：full（全部）/ read（只读）/ publish（仅发布）。In personal settings you can issue a personal token with scope full / read / publish.
  • 个人 Token 等同于账号本身，能调用该账号权限范围内的所有操作。A personal token equals the account itself and can do anything the account can.

8. 社交功能8. Social features

  • 收藏（Star）、评分（Rating）、评论（Comment）：均需登录。Star, Rating, Comment: all require sign-in.
  • 通知（Notifications）：互动与待办提醒。Notifications: interaction and to-do alerts.

10. 下载与安装10. Download & install

  • 技能详情页的「下载 ZIP」按钮（需登录）会把该技能当前所有文件打包下载。The "Download ZIP" button on a skill detail page (requires sign-in) packages all current files.
  • 单个文件（如 SKILL.md）的读取是公开的。Reading a single file (e.g. SKILL.md) is public.
  • 打包下载类操作需要登录。Bundled downloads require sign-in.

11. 给测试人员的注意点11. Notes for testers

  • 注册需审核：新账号提交后默认不能登录，必须管理员通过。Registration needs review: a new account cannot sign in until an admin approves it.
  • 发布即公开：发布表单将「公开」标为"需审核"，但当前发布接口会直接公开（不进审核队列）；选「私有」仅自己/所在命名空间可见。管理员可在后台「内容审核」调整已发布技能的可见性。如界面文字与实际不一致，以实际为准。Publish means public: the form labels "Public" as "needs review", but the publish endpoint makes it public immediately (no review queue). "Private" is visible only to you / your namespace. Admins can adjust visibility of published items in the content-review console. If the UI text disagrees with behavior, trust the actual product.
  • 限流：连续大量请求（尤其下载、发布）会触发限流（返回 429 并带 Retry-After）；正常手动操作不会遇到。Rate limiting: heavy repeated requests (especially downloads/publishes) return 429 with Retry-After; normal manual use won't hit it.
  • 文件大小：单个文件 ≤ 5 MB，单次上传文件数 ≤ 500。File size: each file ≤ 5 MB, up to 500 files per upload.
  • 中文搜索：关键词至少 3 个字才有全文检索效果。Chinese search: keywords need at least 3 characters for full-text search.
  • 一次性密钥：团队 Token 与管理端 API Key 创建后明文只显示一次，务必立即复制保存。One-time secrets: team tokens and admin API keys show their plaintext only once — copy immediately.
  • 命名空间角色：reader 只能查看，不能发布。Namespace role: reader can only view, not publish.
如界面行为与本说明不一致，以实际产品为准，并请反馈给开发同学。If the UI behaves differently from this guide, trust the actual product and report back to the developers.
