1. 产品简介1. Overview

TFI Skill Hub 是一个技能库（Skill Hub）。注册用户可以在这里浏览技能、收藏感兴趣的技能，并下载技能文件。TFI Skill Hub is a skill library (Skill Hub). Registered users can browse skills, favorite the ones they like, and download skill files.

  • 技能（Skill）：一段可被 AI 智能体调用的能力说明，由 SKILL.md 等文件组成。Skill: a capability description an AI agent can call, composed of files such as SKILL.md.

普通用户没有发布、管理、审核等管理员功能，只能进行下方列出的三类操作。Regular users have no admin features such as publishing, management, or moderation — only the three actions listed below.

2. 用户能做什么2. What users can do

普通注册用户只能进行以下三类操作：A regular registered user can only do these three things:

  1. 注册账号Register an account
  2. 收藏 / 取消收藏技能Favorite / unfavorite a skill
  3. 下载技能Download a skill

3. 注册账号3. Register

注册页（/register）：On the register page (/register):

  • 字段：用户名、密码（≥ 8 位）、显示名称（可选）、邮箱（可选）。Fields: username, password (≥ 8 chars), display name (optional), email (optional).
  • 用户名规则：2–32 位，可用字母、数字、点、短横线、下划线，且以字母或数字开头。Username rule: 2–32 chars, letters/digits/dot/dash/underscore, and must start with a letter or digit.
  • 提交注册后，使用「用户名 + 密码」即可登录。After registering, sign in with username + password.

4. 收藏 / 取消收藏4. Favorite / unfavorite

  • 在技能详情页（或技能卡片）点击收藏按钮即可收藏该技能；收藏后按钮显示已收藏，再次点击即取消收藏。On a skill detail page (or a skill card), click the Favorite button to favorite it; once favorited the button shows Favorited, and clicking again removes it from favorites.
  • 收藏状态仅对当前登录账号生效，可在顶部「收藏」页（/favorites）查看已收藏的技能列表。The favorite state applies only to the signed-in account; view the list on the top "Favorites" page (/favorites).

5. 下载技能5. Download

  • 打开任意技能详情页，点击「下载 ZIP」按钮，即可把该技能的文件打包下载到本地。Open any skill detail page and click the "Download ZIP" button to download the skill's files as a package.
  • 下载需要登录账号；未登录时按钮会提示「登录后下载」。Downloading requires sign-in; when signed out the button prompts "Log in to download".

6. 给测试人员的注意点6. Notes for testers

  • 收藏不影响下载：收藏只是把技能加入你的收藏列表，不改变技能本身，也不影响下载。Favoriting does not affect downloading: it only adds the skill to your list; it does not change the skill or block downloads.
  • 下载得到压缩包：下载会把该技能当前文件打包成一个 ZIP 压缩文件保存到本地。Download returns a ZIP: the skill's current files are packaged into a ZIP saved locally.
