1. 产品简介1. Overview

TFI Skill Hub 是一个技能库（Skill Hub）。注册用户可以在这里浏览技能、收藏感兴趣的技能，并下载技能文件。TFI Skill Hub is a skill library (Skill Hub). Registered users can browse skills, favorite the ones they like, and download skill files.

  • 技能（Skill）：一段可被 AI 智能体调用的能力说明，由 SKILL.md 等文件组成。Skill: a capability description an AI agent can call, composed of files such as SKILL.md.

普通用户没有发布、管理、审核等管理员功能，只能进行下方列出的三类操作。Regular users have no admin features such as publishing, management, or moderation — only the three actions listed below.

2. 用户能做什么2. What users can do

普通注册用户只能进行以下三类操作：A regular registered user can only do these three things:

  1. 注册账号Register an account
  2. 收藏 / 取消收藏技能Favorite / unfavorite a skill
  3. 下载技能Download a skill

关于邮箱验证码：系统尚未接入邮件服务，验证码是固定值 123456，不区分邮箱地址。About the verification code: no mail service is connected yet — the code is the fixed value 123456, the same for every address.

获取验证码的步骤Getting the code

  1. 先填写邮箱（未填写时点发送不会有反应）。Fill in Email first (the button does nothing without one).
  2. 点验证码框右侧的「发送验证码」按钮。Click Send code, to the right of the code box.
  3. 按钮变为「N 秒后重发」并置灰 60 秒，期间不可再次点击。The button turns into "Resend in Ns" and is disabled for 60 seconds.
  4. 在验证码框填入 123456，继续填写其余字段并提交。Enter 123456 in the code box, finish the form and submit.

关于倒计时About the countdown

  • 倒计时按邮箱计算：换一个邮箱地址，按钮立即恢复可用（每个地址各有 60 秒）。The wait is per address: change the email and the button is available again (each address has its own 60 seconds).
  • 倒计时刷新页面不会重置：等待由服务端记录，刷新后仍显示剩余秒数。Reloading does not reset it — the wait is kept on the server, so the remaining seconds are still shown.
  • 60 秒结束后按钮变回「重新发送」，可再次发送。When it runs out the button reads "Resend" and can be used again.
  • 修改邮箱地址后，之前填写的验证码会被清空，需要对新地址重新获取。Changing the email clears the code you entered — request a new one for the new address.
  • 提交注册后账号状态为待审核，需管理员审核通过后才能登录；登录时若提示「账号待审核」即表示尚未通过。After registering, the account is pending review and can sign in only after an admin approves it; a "account pending" message at sign-in means it is not approved yet.
  • 提交成功后不会自动登录，需回到登录页用刚注册的账号登录。Submitting does not sign you in — go back to the login page and sign in with the account you just created.
  • 任一必填项未填或填错时，页面会在该字段下方给出红色提示，且不会提交。If a required field is empty or wrong, a red hint appears under it and the form is not submitted.

4. 收藏 / 取消收藏4. Favorite / unfavorite

  • 在技能详情页（或技能卡片）点击收藏按钮即可收藏该技能；收藏后按钮显示已收藏，再次点击即取消收藏。On a skill detail page (or a skill card), click the Favorite button to favorite it; once favorited the button shows Favorited, and clicking again removes it from favorites.
  • 收藏状态仅对当前登录账号生效，可在顶部「收藏」页（/favorites）查看已收藏的技能列表。The favorite state applies only to the signed-in account; view the list on the top "Favorites" page (/favorites).

5. 下载技能5. Download

  • 打开任意技能详情页，点击「下载 ZIP」按钮，即可把该技能的文件打包下载到本地。Open any skill detail page and click the "Download ZIP" button to download the skill's files as a package.
  • 下载需要登录账号；未登录时按钮会提示「登录后下载」。Downloading requires sign-in; when signed out the button prompts "Log in to download".

7. 给测试人员的注意点7. Notes for testers

  • 收藏不影响下载：收藏只是把技能加入你的收藏列表，不改变技能本身，也不影响下载。Favoriting does not affect downloading: it only adds the skill to your list; it does not change the skill or block downloads.
  • 下载得到压缩包：下载会把该技能当前文件打包成一个 ZIP 压缩文件保存到本地。Download returns a ZIP: the skill's current files are packaged into a ZIP saved locally.
  • 管理员功能与上述无关：第 6 节的管理后台仅 admin 账号可用，普通测试账号无需使用；若以普通账号访问 /admin 会被跳转到登录页。Admin functions are separate: the admin console in section 6 is for admin accounts only; a regular test account does not need it, and visiting /admin as a normal user redirects to sign-in.
如界面行为与本说明不一致，以实际产品为准，并请反馈给开发同学。If the UI behaves differently from this guide, trust the actual product and report back to the developers.
